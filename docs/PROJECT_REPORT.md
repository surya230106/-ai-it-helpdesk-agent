# AI IT Helpdesk Agent — Mini Project Report

## Abstract
The AI IT Helpdesk Agent is a web-based support system that helps users diagnose routine technical problems. It combines an LLM agent, Retrieval-Augmented Generation (RAG), structured tools, memory, and ticket escalation. Users describe an issue in natural language. The system classifies the issue, retrieves relevant knowledge-base content, applies a safe troubleshooting checklist, and returns a clear response with supporting source snippets. Unresolved issues can be recorded as tickets for human support.

## Objectives
- Reduce time spent on repetitive IT support questions.
- Ground recommendations in an organization's knowledge base.
- Provide safe and consistent troubleshooting steps.
- Preserve a human escalation route.

## Modules
1. Authentication
2. AI Helpdesk Chat
3. RAG Knowledge Base
4. Agent Tools
5. User Memory
6. Ticket Management
7. Dashboard

## Conclusion
The project demonstrates how agentic AI can combine retrieval, deterministic tools, and persistent context to support IT helpdesk workflows while keeping high-risk actions under human control.
